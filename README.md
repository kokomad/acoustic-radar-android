# الرادار الصوتي الخفي — تطبيق أندرويد

## طريقة الاستخدام على GitHub
1. أنشئ مستودعًا جديدًا على GitHub (مثلًا `acoustic-radar`).
2. ارفع كل محتويات هذا المجلد إلى فرع `main` (مجلد `.github` مهم).
3. افتح تبويب **Actions** ← **Build Android APK**. يبدأ البناء تلقائيًا، أو اضغط **Run workflow**.
4. بعد نحو 5 دقائق افتح التشغيل الناجح ونزّل **acoustic-radar-apk** من قسم Artifacts.
5. فك الضغط وثبّت `app-debug.apk` على هاتفك (فعّل «التثبيت من مصادر غير معروفة»).

## ملاحظات
- الكود الرئيسي في `www/index.html`، وأي تعديل عليه يعيد بناء الـ APK عند الرفع.
- خط Tajawal يُحمَّل من الإنترنت، وبدونه يستخدم التطبيق خطًا بديلًا.
- الملف المنتج نسخة تجريبية (debug). للنشر على Google Play تحتاج توقيعًا (keystore) وبناء release.
